# Code Index — main code blocks per file

Lookup hints below use file paths plus a function/section name (no line numbers; grep/Ctrl-F by name).

## Top-level / build

- [wowaddon.py](../wowaddon.py) — Python build/install tool. `VERSION` constant near top. `BuildTool` class: `__init__` writes per-flavour TOCs, `do_install` (copy dirs into Addons folder), `do_zip` (build CurseForge zip), `do_zip_add_dir` / `do_zip_add_root_dir` (recursive), `git_hash`, `create_toc` (template substitution). `main()` argparse entry. Suffix constants: `SUFFIX_CLASSIC`/`-BCC`/`-WOTLKC`/`-Cata`. UI version constants per expansion.
- [toc_template.toc](../toc_template.toc) — TOC template with `${UI_VERSION}` / `${VERSION}` / `${ADDON_TITLE}` placeholders. Authoritative load order — first `embeds.xml`, then `Src/EarlyBoot.lua`, `Src/KvLib/KvEnv.lua` + `KvUnit` / `KvPlayer` / `KvEvents`, `Src/Buffomat.lua`, `Src/KvLib/KvOptions.lua`, then `Src/Const/`, `Src/Knowledge/`, then `Src/Core/`, `Src/Task/`, `Src/Cache/`, `Src/Scan/`, `Src/Ui/`, then `Src/Events.lua`, `Src/SpellSetup.lua`, `Src/BuffChecks.lua`, then `Src/Languages/`, then `Src/Toolbox/`.
- [embeds.xml](../embeds.xml) — Loads Ace3 libs in order: `LibStub`, LibDBIcon stack (CallbackHandler, LibDataBroker, LibDBIcon-1.0), CallbackHandler, AceAddon-3.0, AceGUI-3.0, AceTimer, AceEvent, AceConsole, AceConfig, LibUIDropDownMenu.

## Bootstrap / addon entry

- [Src/EarlyBoot.lua](../Src/EarlyBoot.lua) — Single-purpose: `LibStub:NewLibrary("Buffomat-…", 1)` calls registering every module name. Always edit here when adding a new module.
- [Src/Buffomat.lua](../Src/Buffomat.lua) — Main addon file. Module wiring (LibStub locals at top), `BomAddon` class type spec with the addon-wide state fields, `BuffomatAddon = LibStub("AceAddon-3.0"):NewAddon(...)`. Functions: `BuffomatAddon:Debug`, `buffomatModule:Color`, `buffomatModule.OptionsUpdate`, `buffomatModule:OptionsInit`, `buffomatModule.ChooseProfile`, `buffomatModule:UseProfile`, `buffomatModule:UpdateBuffTabText` (group label "G1-3,5"), `buffomatModule:InitUI` (registers minimap LDB, starts the scan scheduler), `buffomatModule:InitGlobalStates` (saved-vars init + profile migration), `BuffomatAddon:MakeSlashCommand` (slash table, incl. `/bom scanstats`), `BuffomatAddon:Init` (real entry — translations, const, allBuffs, macro, slash, UI), `RegisterBindings`, AceAddon handlers `OnInitialize` / `OnEnable` / `OnDisable`, `buffomatModule:OnFailedCast_LearnedDownrank` (downrank learning from UI errors), hyperlink handlers `EnterHyperlink` / `LeaveHyperlink` / `ClickHyperlink`.
- [Src/Events.lua](../Src/Events.lua) — `EventsModule`. Only the handlers which are not scanning (AceEvent): error-message lists `ERR_NOT_STANDING/IS_MOUNTED/IS_SHAPESHIFT`, `Event_TAXIMAP_OPENED`, `Event_CombatStart/Stop` (cancel buffs, skip list, window), `Event_LoadingStop` (one-time item/spell preload), `Event_PLAYER_TARGET_CHANGED` (`lastTarget` for the force-target dialog), `Event_UI_ERROR_MESSAGE` (auto-stand/dismount/cancelform, skip list), `Event_PLAYER_LEVEL_UP`, `Event_TALENT_GROUP_CHANGED`, `Event_SpellsChanged`. `eventsModule:InitEvents` also starts `ScanEvents`. Events which change what a scan finds are in `Src/Scan/ScanEvents.lua`.

## Scanning (`Src/Scan/`)

Design and history: [.agents/scan-plan.md](scan-plan.md). These modules call no WoW API directly, only `Src/KvLib/` (luacheck enforces it, also for `Src/Task/` and `BuffChecks.lua`).

- [Src/Scan/ScanScheduler.lua](../Src/Scan/ScanScheduler.lua) — `ScanSchedulerModule`. Decides when a pass runs. Dirty domains (`BomScanDomain`), intervals (`COALESCE`, `MIN_GAP`, `CONTINUATION`, `RANGE_TICK`, `DEAD_WATCH`, `RESYNC`, `FLIGHT_WATCH`, `ERROR_RETRY`; doubled by `SlowerHardware` in `:Interval`). `:MarkDirty(domain, unitId)`, `:MarkUnit`, `:MarkAllDirty(reason)`, `:Request(reason)` (settings: evaluate only), `:WakeAt(time, domain)` / `:WakeAfter` / `:CancelWake` (deadlines), `:SchedulePass`, `.OnTimer` (runs `ScanPass:Run` through `envModule.SafeCall`, handles "continue", "blocked" and an error), `:BeginPass` / `:RestorePending`, gates `:IsOpen`, `:Start`, `:OnCombatStart/End`, `:OnLoadingStart/End` (grace time).
- [Src/Scan/ScanEvents.lua](../Src/Scan/ScanEvents.lua) — `ScanEventsModule`. One `KvEventDispatcher` for every event which changes what a scan finds; each handler only marks a domain. `:Init` (the event table), `:RegisterAuraEvent` (UNIT_AURA client-filtered to player and pet when alone; not taken in combat), `:SetManaWatch`, `modifierWatch`.
- [Src/Scan/ScanPass.lua](../Src/Scan/ScanPass.lua) — `ScanPassModule`. One pass: `:Run(pending, pendingUnits)` (gate and aura-free mode, profile, `:Read`, early out through `:HasChanged`, `:Evaluate`, `:ArmWatchTimers`). `:Evaluate` = inactive check, `ScanEvaluate:Evaluate`, `TaskBuilder:Build`, `ScanEffects:Run`, `:Present`. `:ShowInactive`. Owns `result` and `tasklist`.
- [Src/Scan/RosterScan.lua](../Src/Scan/RosterScan.lua) — `RosterScanModule`. `BomRoster` (units in read order, `byUnitId`, `byName`, `groups`, `player`, `playerPet`, `target`, `incomplete`, `hasDead`, `version`). `:Rebuild(pendingUnits, playerOnly)` (one reused `BomUnit` per unit id, identity by GUID), `:NeedsRebuild`, `:ReadStatus` / `:ReadStatuses` (dead, ghost, connected, zone, incoming resurrection), `:ForgetResurrections`.
- [Src/Scan/AuraScan.lua](../Src/Scan/AuraScan.lua) — `AuraScanModule`. `:ReadUnit` (helpful auras into `knownBuffs` / `allBuffs`, pooled records, duration learning, change signature), `:MarkUnreadable`, `:SetAuraFree`, `:Enqueue`, `:ReadQueued` (budget of 10 units per pass, roster order), `version`, `drinkingCount`.
- [Src/Scan/BagScan.lua](../Src/Scan/BagScan.lua) — `BagScanModule`. `:Read` (one walk, `byItemId` index and `openable` list, change signature), `:NeedsRead`, `:InvalidateCooldowns`, `:Find`, `:Count`, `:GetCooldown` (lazy), `:IsReady` (wakes the scheduler when the cooldown ends), `:IsOpenable`.
- [Src/Scan/PlayerStateScan.lua](../Src/Scan/PlayerStateScan.lua) — `PlayerStateScanModule`. Snapshot of mana, level, dead, mounted, flying, taxi, vehicle, resting, stealth, outdoors, PvP flag, form, instance, pet, tracking (`:Read`); `:ReadMana` (for every evaluation, not a change), `:CanTakeOff` (flight watch); trinkets, weapons and temporary weapon enchants (`:ReadEquipment`, `:ApplyEquipment`, `enchantExpiresAt`); `casting` (set by events), `manaWakeLimit`, `:IsTrackingActive`.
- [Src/Scan/RangeScan.lua](../Src/Scan/RangeScan.lua) — `RangeScanModule`. `:BeginPass`, `:Distance(unit)` (measured on demand, once per pass), `:NearestInGroup`, `:NearestOfClass`.
- [Src/Scan/ScanResult.lua](../Src/Scan/ScanResult.lua) — `ScanResultModule`. `BomBuffNeed` (units, groups, groupsHaveDead, betterBuff, reminderText) and `BomScanResult` (needs per buff, `trackingToActivate`, `buffsToCancel`, `activeAura` / `activeSeal`, `forceTracking`, `needsModifierKey`, `itemTargets`). `:New`, `:Reset`, `:Need(buffDef)`, `:ClearNeed`.
- [Src/Scan/ScanEvaluate.lua](../Src/Scan/ScanEvaluate.lua) — `ScanEvaluateModule`. Decides from the snapshots. Activity: `:IsActive` (instance/world/PvP/rest area/stealth/mount/Spirit Tap), `:IsAuraDataComplete`, `:IsInGlobalCooldown` (spell 61304), `:IsMountedAndCrusaderAuraRequired`, `:IsFlying`, `:GetInactiveReason`. Needs: `:Evaluate(roster, result, auraFree)`, `:EvaluateBuff` (dispatch by buff kind to `BuffChecks`), `:SelectTracking`, `:SelectAuraAndSeal`, `:SelectBuffsToCancel`, `:IsAuraFreeBuff`.
- [Src/Scan/ScanEffects.lua](../Src/Scan/ScanEffects.lua) — `ScanEffectsModule`. What a scan does to the game: `:Run(result, player)` (cancel buffs, activate tracking), `:CancelBuff`, `BuffomatAddon.CancelShapeShift`, `BuffomatAddon.DoCancelBuffs` (combat start), `:ActivateTracking`, skip list (`BuffomatAddon.AddMemberToSkipList`, `:ClearSkip`), `:MaybeResetWatchGroups`, `:PlayTaskSound`, `:NotifyPvPMatchOnce`.
- [Src/Scan/ScanStats.lua](../Src/Scan/ScanStats.lua) — `ScanStatsModule`. Counters behind `BuffomatShared.DebugLogging`: `:Count`, `:Reason`, `:PassBegin` / `:PassEnd`, `:Report`, `:Print` (`/bom scanstats`), `:Reset`.

## Shared (KvLib)

- [Src/KvLib/KvEnv.lua](../Src/KvLib/KvEnv.lua) — `KvSharedEnvModule` aka `envModule`. `WOW_PROJECT_ID` flags: `isClassic`, `isTBC`/`haveTBC`, `isWotLK`/`haveWotLK`, `isCata`/`haveCata`, `isMistsOfPandaria`. `isForever` comes from the 16xxx interface range, not `WOW_PROJECT_ID`. Capability flags `groupBuffsRaidWide` (WotLK+, Forever) and `hasDualSpec`; helpers `IsEventValid` (C_EventUtils guard), `SafeCall` (xpcall which reports to the client's error handler), `IsPlayerSpell` (talents and Legacy talents), `GetItemClass` (class/subclass via GetItemInfoInstant), `GetItemSubClassName`. C_Container compatibility shims: `GetContainerNumSlots`, `GetContainerItemInfo`, `ReadContainerItem` (plain values, no table per slot), `GetContainerItemCooldown` (nil when secret), `ContainerItemTooltipHasLine` / `IsContainerItemLockedBox`, `GetAddonMetadata`. Spells: `GetSpellInfo`, `GetSpellSubtext`, `GetSpellCooldown`, `IsSpellInRange`, `IsSpellKnown`, `GetSpellPowerCost`. Restrictions: `GetAuraRestriction` (name of the active aura-hiding restriction, PvPMatch reported only when alone), `IsAuraRestricted`, `GetUnitAura`. `UnitIsUnit`, `UnitPower`, `UnitPowerMax`, `UnitInRange`, `IsItemInRange` (secret-safe), tracking (`usesTrackingSettings`, `GetTrackingInfo`, `SetTracking`), `GetWeaponEnchantInfo`. `playerBagIds` (backpack, bags, and the Mainline/Forever reagent bag). `playerClass`.
- [Src/KvLib/KvUnit.lua](../Src/KvLib/KvUnit.lua) — `KvUnitModule`. Unit, group and aura queries which never return a secret value: `GetName` / `GetGUID` (with an "unreadable" flag), `GetPlayerClass` (by GUID), `GetClass` (by unit; players only), `Exists`, `IsDead` (not feigning), `IsGhost`, `IsConnected`, `HasIncomingResurrection`, `GetMapId`, `HasTankRole`, `IsPVP`, `GetLevel`, `GetCreatureTypeId` / `GetCreatureFamilyId`, `IsInRaid`, `IsInGroup`, `GetNumRaidMembers`, `GetRaidSlot` (subgroup and role), `IsBuffableOutsider`, `ReadAura` (one aura as plain values, no table), `AuraUpdateTouchesBuffs` (UNIT_AURA payload filter), `DistanceSquared` (exact or by item / interact ranges; `TOO_FAR`, `UNKNOWN_DISTANCE`).
- [Src/KvLib/KvPlayer.lua](../Src/KvLib/KvPlayer.lua) — `KvPlayerModule`. Player state with APIs which exist only on some clients: `IsMounted`, `IsFlying`, `IsResting`, `IsStealthed`, `IsOutdoors`, `IsOnTaxi`, `IsInVehicle`, `IsDeadOrGhost`, `GetShapeshiftFormID`, `GetShapeshiftForm`, `GetInstanceType`, `GetInstanceId`, `GetInventoryItemID` / `Link`, `IsModifierKeyDown`, `IsAltKeyDown`, `GetLatency`, `CancelAura`, `CastSpellByID`, `PlaySoundFile`, `GetProfileTime`.
- [Src/KvLib/KvEvents.lua](../Src/KvLib/KvEvents.lua) — `KvEventsModule`. `NewDispatcher()` returns a `KvEventDispatcher`: one frame dispatching by event name. `:On` (refuses events the client does not have), `:OnUnit` (unit-filtered, with a fallback filter where the client has no `RegisterUnitEvent`), `:Off`, `:IsRegistered`.
- [Src/KvLib/KvOptions.lua](../Src/KvLib/KvOptions.lua) — `KvOptionsModule`. Generic AceConfig template builders used by Options.lua: `:ValueToText` / `:TextToValue`, `:TemplateCheckbox`, `:TemplateButton`, `:TemplateMultiselect`, `:TemplateSelect`, `:TemplateInput`, `:TemplateRange`. Increments shared `optionsOrder`.
